写这篇的初衷：背包问题是 DP 的入门，但也是很多人的”劝退点”。状态转移方程背了就忘，一维优化搞不清正序倒序。这篇试着从”购物决策”的直觉出发，帮你理解每个方程背后的含义。

DP 的本质：把复杂问题拆成子问题，记住子问题的答案（状态），用子问题的答案拼出原问题的答案（转移）。

一、DP 的核心思维：状态设计 + 状态转移

先别急着看代码，想清楚两件事

1. 状态表示：f(i, j) 到底是什么意思？

背包问题里，f(i, j) 通常表示：

“只从前 i 个物品里选，且总体积不超过 j 的所有选法中，价值最大的那个方案的价值”

拆开看：

  • 集合：所有满足条件的选法
    • 条件 1：只从前 i 个物品里选
    • 条件 2：总体积 ≤ j
  • 属性：max（最大值）、min（最小值）、count（方案数）

二、01 背包：每个物品只能选一次

三、完全背包：每个物品可以选无限次

问题描述

和 01 背包一样，但每个物品可以选任意多次（只要装得下）。

生活比喻：超市里的散装糖果，可以随便抓，只要袋子装得下。

朴素思路（三重循环）

最直接的想法：枚举每个物品选多少个。

问题：时间复杂度 ，太慢了！

优化思路：利用已经算过的结果

关键观察：

直觉解释：

  • f[i][j-v] 已经算过”在体积 j-v 下，前 i 个物品的最优解”
  • 这个最优解里可能已经选了若干个物品 i
  • 现在体积变成 j，只需要在 f[i][j-v] 的基础上再多选一个物品 i 就行

二维优化写法

和 01 背包的区别：f[i][j - v[i]] vs f[i-1][j - v[i]]

  • 01 背包：不能选第 i 个，所以用 f[i-1]
  • 完全背包：可以再选一个第 i 个，所以用 f[i]

为什么这次要正序？

因为完全背包允许重复选，我们需要 f[j - v[i]] 是当前层已经更新过的值（可能已经选了若干个物品 i）。

结论：正序枚举让 f[j - v[i]] 是当前层的值，符合完全背包”可以重复选”的要求。

记忆口诀：

完全背包要正序，允许物品重复选

四、多重背包：每个物品有数量限制

问题描述

每个物品 i 最多选 s[i] 次（不同物品的数量限制可能不同）。

生活比喻：超市限购，每人最多买 5 瓶牛奶。

朴素写法（三重循环）

问题：如果 s[i] 很大（比如 1000），复杂度会很高。

二进制优化：把多重背包转成 01 背包

核心思想：把 s 个物品打包成若干组，每组看作一个”新物品”，然后用 01 背包解决。

打包策略：用二进制拆分

数学原理：

  • 1, 2, 4, …, 2^k 可以组合出 0 到 2^(k+1)-1 的任意整数
  • 剩下的部分 c = s - (2^(k+1) - 1) 保证 c < 2^(k+1)
  • 这样打包后，任意 0 到 s 的数量都能被表示

五、分组背包：每组最多选一个

问题描述

有 n 组物品，每组有若干个。每组最多选一个物品，求最大价值。

生活比喻：餐厅点菜，每类菜（主食、主菜、饮料）只能选一道。

状态设计

和之前一样，f[j] 表示”体积不超过 j 的最大价值”。

转移思路：对于第 i 组，枚举选组内的哪个物品（或者不选）。

六、四种背包问题对比总结

类型 限制条件 枚举方向 转移方程
01 背包 每个物品选 0 或 1 次 体积倒序 f[j] = max(f[j], f[j-v] + w)
完全背包 每个物品选无限次 体积正序 f[j] = max(f[j], f[j-v] + w)
多重背包 每个物品选 ≤ s 次 体积倒序 + 二进制拆分 转成 01 背包
分组背包 每组选 0 或 1 个 体积倒序 f[j] = max(f[j], f[j-v[i][k]] + w[i][k])

八、易错点总结

  1. 01 背包倒序，完全背包正序 —— 最容易记混
  2. 多重背包二进制拆分 —— 别忘了最后剩下的部分
  3. 分组背包循环顺序 —— 组→体积→组内物品，不能乱
  4. 数组下标 —— 从 0 还是从 1 开始，要统一
  5. 初始化 —— 求最大值时初始化为 0 或 -∞，求方案数时初始化为 0 或 1

最后提醒：背包问题的核心不是背模板，而是理解状态设计和转移方程背后的逻辑。多画图、多模拟，比死记硬背有效得多。
