数位统计 dp

分情况讨论！

[a,b] 0~9

若能实现 count(n,x) 1~n 中 x 出现的次数

则 ans = count(b,x) - count(a-1,x)

以 x =1 为例
对于一个 7 位 数字
分别求出 1 在 每一个位上出现的次数

例如 在 第 4 位上，分情况讨论=>
1 <= xxx1yyy <=abcdefg
(1) xxx = 000abc-1, yyy = 000999 => abc * 1000
(2) xxx= abc,
(2.1) d<1, abc1yyy >abc0efg => 0
(2.2) d=1, yyy=000efg => efg +1
(2.2) d>1, yyy=000999 => 1000

再考虑边界情况

当枚举 0 的 时候，需要从 100~abc-1 // 不能有前导0
因为，如果从 001 开始取，那就不是 第 4位了，而是第2 位

核心思路（非常重要）

我们定义一个函数：

count(n, x) = 1 ~ n 中，数字 x 出现的次数

那么答案就是：

count(b, x) - count(a-1, x)

👉 所以问题变成：怎么求 count(n, x)

🔍 按位拆分（重点）

以某一位（比如第 k 位）为例：

把 n 拆成三部分：

高位 + 当前位 + 低位

例如：n = abcdefg
↑ ↑ ↑
高位 当前 低位
🧩 对每一位统计 x 的贡献

设：

high = n / (10^(k+1))
cur = 当前位
low = n % (10^k)
🎯 分类讨论（通用公式）

对于 x ≠ 0：

情况：

cur > x

(high + 1) * 10^k

cur == x

high * 10^k + (low + 1)

cur < x

high * 10^k
❗特殊：x = 0（重点坑点）

👉 不能统计前导 0！

所以：

high 需要减 1
情况：

cur > 0

(high - 1 + 1) * 10^k = high * 10^k

cur == 0

(high - 1) * 10^k + (low + 1)

cur < 0（不存在）

(high - 1) * 10^k

👉 本质就是：最高位不能是 0

状态压缩 dp

核心思想：用一个整数来表示一种状态

蒙德里安的梦想
思路：当横向摆好后，纵向依次放入即可
所以，总方案数只与横向摆放方案数有关

用 f[i][j] 表示 第 i 列，j （10010）表示该列 第1、4行拜访了横木块的右端点
f[i][j] 从 f[i-1][k] 转移需要满足以下两点要求

  1. j& k== 0// 不能有冲突
  2. j | k 不能有奇数个连续的0 // 竖木块无法填充

  1. 状态表示

    • f[i，j] 表示什么？

    • 所有从 0 走到j，走过的所有点存在 i 的路径最小值

    • 集合是什么？（所有满足某条件的方案）
      所有从 0 走到j，走过的所有点存在 i 的所有路径
      i 是一种状态压缩 ，比如 i=(10010)2 表示 第0个点 和 第3个点走过了

    • 属性是什么？（总路径权重最小值 ）

  2. 状态转移

    • 如何划分子问题 集合划分
      以倒数第二点划分 0 ->k ->j
    • 转移方程是什么？
  • f[i - {j},k] + a[k][j]

题意概述
N 个任务，每个任务有(Ci，mi，Ui)。每台服务器有CPU上限C、内存上限M。对于K = 1..N，分别求有K台服务器时可获得的最大总价值。

lb = s& -x
i = __builtin_ctz(lb);
prev = s^ sub;

从大到小遍历 s 的sub： sub = s;sub;sub = (sub-1) & s

s = 1101
sub = 1101
sub = 1100 & 1101 = 1100
sub = 1001 & 1101 = 1001
