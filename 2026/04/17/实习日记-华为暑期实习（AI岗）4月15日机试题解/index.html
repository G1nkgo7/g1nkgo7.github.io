写在前面

主包小丑了🤡。报的 AI 应用研发岗，以为是研发岗标准的三道编程题，结果 15 号机试一看：单选 + 多选 +（150）+ 两道编程（150+300），纯纯 AI 相关岗位的卷子……

主包 A 完两道编程题后，看选择题难度有点高，只把有把握的写了，剩下的随便蒙了就交卷，全程大概 1h 左右。

之后复盘刷了些之前 AI 岗的真题，总结规律如下：

  • 选择题：难度偏高，覆盖离散数学、概率论、DL、ML、LLM、强化学习、数据集等
  • 编程题：一般是一道模拟 + 一道简单算法（题目描述可能复杂，但可抽象成 DP、贪心等经典模型）
  • 语言差异：主包是 CPP 选手，听说有场考了矩阵求逆，完全不会……庆幸没碰到，不然直接 -300，这题 PY 选手会舒服很多

回到编程题本身，AI 岗的编程题难度其实还好：

  • 通常有一道 模拟题，给出算法的具体思路，让你实现
  • 需要对该算法有基本了解，完全不知道的话会麻烦些，但本质上还是模拟，难度不会太高

依旧从编程题入手。

2. 大模型调用资源分配最小成本

题目描述

给定 N 个大模型调用请求，每个请求有优先级数值。需要为这些请求分配计算资源单位（单位：千 token），要求：

  1. 有效分配：优先级 > 0 的请求才需要分配资源；优先级 ≤ 0 的视为无效，不分配 token
  2. 每个有效请求至少分配 1 千 token
  3. 相邻的有效请求中，优先级较高的必须分配更多的 token
  4. 目标：在满足所有有效请求的前提下，使总 token 数最小
输入描述

一行逗号分隔的整数，表示各请求优先级。

题意概述

给一组优先级，过滤掉 ≤ 0 的无效请求。每个有效请求至少 1 token，相邻请求中优先级高的必须 token 更多。求最小总 token 数。

思路

经典「分发糖果」问题，双向扫描贪心：

  1. 过滤无效请求（优先级 ≤ 0）
  2. 初始化每个有效请求为 1 token
  3. 左→右扫描：右边优先级 > 左边时，右边 token = 左边 + 1
  4. 右→左扫描：左边优先级 > 右边时，左边 token = max(原值，右边 + 1)
  5. 求和
