vector ls(n + 1);

vector head(n + 1, 0);

加边

function<void(int u, int v, int w)> add = [&](int u, int v, int w) {
    ls[++tot].to = v;
    ls[tot].w = w;
    ls[tot].next = head[u];
    head[u] = tot;
};

// 强调一下前向星的遍历方式，我这里以 0 为结束标识

return;

拓扑排序

图的 bfs 的一个应用
针对有向图无环图 一定存在拓扑序列

一个 有向图无环图 一定存在一个入度为0 的点（可以通过反证法 + 抽屉法 证明）

可以判环，如果不存在拓扑序列，就存在环

从起始点（入度为0 的点）出发，依次去除前驱

当前点的 所有出边的 点 入度 - 1
如果入度 == 0，就可以入队了

如果存在环，入度不会为0，可以维护一共入队了多少，就可以判环了

注意 拓扑序列并不唯一

OJ 中对于这种多解 使用 Special Judge（SPJ，特判） 判断的

从一个点到其他所有点的最短路

    2. spfa (如果限制经过的边数不超过k个，则无法使用)

Dijkstra 不能有负权边

朴素 Dijkstra

O(n^2) 适合稠密图 m ~ n^2 // n 是点 m 是边

集合 s 当前已经确定了最短距离的 点

  1. 初始化距离 dis[1] = 0,dis[1] = inf;
  2. for i : 0~n
    不在 s 中的 距离最近的点 t（最小的dis[t]）
    s inset t
    用 t 更新 其他所有点的距离： dis[x] > dis[t] + w(t,x) 就更新 （贪心可以证明）
    每一次迭代可以确定一个点的最短距离

稠密图 用邻接矩阵
稀疏图 用邻接表

如果出现 重边：保留 距离最短的
自环，如果为 正，则一定不存在于最短路里，可以忽略

O(mlogn) 适合稀疏图 m ~ n
用邻接表

bellman-ford

O(mn)

处理 有负权边的；
有负权边的情况下，最短路不一定存在。

也可以用来找 负环
第 n 次的时候，如果还发生了更新，那这条路径上一定有负环

dist[v] <= dist[u][w] // 三角不等式

适用于求 有边数限制 的 最短路径 的情况

for n次
for 所有边 （u,v,w)
dist[v] = min(dist[v],dist[u]+w); // 松弛操作

最坏: O(mn)

唯一限制：图中不能有 负环
bellman-ford 的优化
只有一个点更新过了，他后续的更新才有效

用一个队列维护更新过的点

queue <- 1
while(queue 不空）

  1. t = q.front()
    q.pop()
  2. 更新 t 的所有出边
    t ->b
    更新过的 入队
    queue <- b

spfa 被卡了是什么意思？
可以在构造数据的时候，吧 spfa 算法 卡成 O(mn)的，这时候就很慢了
一般情况是 O（n) 如果被卡了，就换堆优化的 dijk

// 如何判负环？

用 dist[x] 表示 1~x 的最短距离
cnt[x] 表示 当前最短路的边的数量

dist[x] = dist[t] + w[i];
cnt[x] = cnt[t]+1;
if cnt[x] >=n 的时候
那存在负环

如果不是判断 从 1 开始存在负环
那就一开始把所有点放入 q 中，（注意重点）
就可以判断图中是否存在负环

原理：动态规划
d[k,i,j] 从 i 点 只经过 1~k 这些点 到 j 的最短距离
d[k,i,j] = d[k-1,i,k]+d[k-1,k,j]
优化掉第一位
d[i,j] = d[i,k]+d[k,j]
